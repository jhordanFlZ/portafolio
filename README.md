# Portafolio Immersive

Base creativa construida con `Three.js`, `GSAP` y `Vite`.

## Scripts

- `npm start`: levanta el entorno local.
- `npm run build`: genera la version de produccion.
- `npm run preview`: previsualiza el build.

## Stack

- `Three.js` para la escena WebGL
- `GSAP` para entradas y transiciones
- `Vite` para desarrollo y build
